Stripe Payment
1    install stripe 

composer require stripe/stripe-php




2 - go to https://dashboard.stripe.com/ create an account

next :   go to developers /  api key  and  take your public & secret key


3 - in your .env file  add  your stripe key s 

STRIPE_KEY=pk_*******************
STRIPE_SECRET=sk_************************


4 - in your config/stripe.php add 

<?php

return [
    'pk' => env('STRIPE_KEY'),
    'sk' => env('STRIPE_SECRET'),
];


5 - in your controller    you have to
 import your key from stripe.php  (stripe.php import keys from env as well )

  public function checkout()
    {
        Stripe::setApiKey(config('stripe.sk'));
        
        $session = Session::create([
            'line_items'  => [
                [
                    'price_data' => [
                        'currency'     => 'usd',

                    ],

            'success_url' => route('dashboard'), // route when success 
            'cancel_url'  => route('stripe.payement'), // route when  failed or canceled
        ]);

        return redirect()->away($session->url);
    }
